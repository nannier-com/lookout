Large soft-radius surfaces, machined nesting (an outer tray holding an inner
core with concentric corners), capsule buttons whose trailing icon sits in its
own small circle, a floating pill navigation detached from the top edge, a tiny
uppercase eyebrow tag before each major heading, heavy vertical space between
sections, ultra-light line icons, wide diffused tinted shadows.

### Chosen on purpose

These are this direction's own language. Never file them as tells.

- Exactly two rings, an outer tray and an inner core with concentric corners,
  is this direction's card. A third ring inside the core is still the craft
  panel's composition finding.
- The eyebrow tag above a heading, and the circle around a button's trailing
  arrow, are the direction, never the idle-badge tell.
- Capsule primary buttons and generous rounding are expected, never the
  stock-hero tell on their own.
- A mesh of soft colour orbs far behind a dark canvas is this direction's
  texture; file blob-backdrop only where it competes with the content in
  front of it. A flat violet-to-blue wash on a button or a hero is still the
  ai-gradient tell.

### What this direction adds

Filed under taste, with the attribute named, where a still shows it.

- Filed as taste, attribute off-direction-shape: a navigation bar running edge
  to edge and glued to the top of the viewport; three equal columns with no
  generous space around them; a card sitting flat on the background with a
  plain mid-grey solid border. Consequence: reads as a framework default
  rather than a built surface.
- Filed as taste, attribute off-direction-shadow: a hard, dark drop shadow
  under any element. Consequence: depth in this direction is diffuse, and one
  hard shadow reads as a second lighting model.
- Filed as taste, attribute off-direction-icon: icons drawn at a heavy stroke
  beside the direction's light ones; a trailing arrow sitting naked beside
  button text. Consequence: one heavy glyph among light ones reads as a
  different icon set.

The geometry panel's spacing rule is unchanged, but in this direction the
expected rhythm is heavy space, so a heading that nearly touches the previous
section's content is filed there without hesitation. Everything the other
panels own, and every default tell not waived above, is filed as usual.
