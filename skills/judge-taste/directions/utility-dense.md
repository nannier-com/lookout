A working tool: dashboards, admin panels, consoles. Information density is the
point. Groups are separated by rules and space rather than boxed; numerals sit
in columns; the type is a sans, with a monospace welcome for figures; colour is
reserved for state (success, warning, error, selection) and for one primary
action; nothing is decorated.

### Chosen on purpose

These are this direction's own language. Never file them as tells.

- A dense first screen is the direction. File first-screen crowding only where
  the density is decoration (widgets with no data, charts with nothing to say)
  rather than information.
- A row of equal stat tiles is a dashboard's own furniture when each tile
  carries a real figure; file the round-stats tell only where the figures are
  placeholders.
- Terse labels, abbreviations and all-caps column headers are the register,
  never a copy-voice tell.

### What this direction adds

Filed under taste, with the attribute named, where a still shows it.

- Filed as taste, attribute off-direction-shape: a bordered, shadowed card
  wrapped around every single metric or list row so the boxes outnumber the
  data; a marketing hero (headline, subline, capsule buttons) at the top of a
  working screen. Consequence: the frame costs more space than the data, and
  the page reads as a landing page for itself.
- Filed as taste, attribute off-direction-colour: a decorative gradient, glow
  or illustration on a working surface; a state colour used decoratively so a
  red or a green no longer means anything. Consequence: the reader can no
  longer trust colour to mean state.
- Filed as taste, attribute off-direction-type: a serif display face on a
  working screen; an emoji in a status or label. Consequence: the register
  breaks, and a tool reads as a brochure.
- Filed as taste, attribute off-direction-voice: a working screen speaking
  marketing ("Supercharge your workflow") in an empty state or a banner.
  Consequence: the reader came to do something and is being sold it instead.

Everything the other panels own, and every default tell not waived above, is
filed as usual.
