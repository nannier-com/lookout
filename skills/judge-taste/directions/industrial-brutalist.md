Swiss print or terminal telemetry: square corners everywhere, visible rules
compartmentalising the page, monolithic uppercase headings against small
uppercase monospace metadata, one substrate (unbleached paper, or near-black
phosphor) and one hazard-red accent. Technical markers are the typography.

### Chosen on purpose

These are this direction's own language. Never file them as tells.

- Bracketed codes, revision strings, crosshairs, registration and trademark
  marks used as graphic elements, numbered section markers, ASCII framing and
  directional glyphs are this direction's vocabulary, never the meta-label or
  fake-marker tell. File an ornament only where it sits on top of content or
  is the only thing on a surface that should carry data.
- Scanlines, halftone, dither and grain over images and display type are
  intended degradation, not noise hiding the layout. A near-black canvas is
  intended.
- All-capitals metadata, navigation and headings are the direction; never
  file case. Generated marketing vocabulary is still filed.
- A grid of equal compartments divided by rules is the direction, not a card
  row; three equal compartments are not the feature-triplets tell.
- Bimodal density (packed metadata against vast empty space) is deliberate;
  file first-screen crowding only where the packed zone has no empty
  counterweight anywhere in the first screen.

### What this direction adds

Filed under taste, with the attribute named, where a still shows it.

- Filed as taste, attribute off-direction-shape: any visibly rounded corner on
  any surface or control; any gradient, soft or diffused shadow, or
  translucent surface. Consequence: one soft element breaks the mechanical
  rigidity every other element asserts and reads as a kit component left
  unstyled.
- Filed as taste, attribute off-direction-colour: a second chromatic accent
  beside the red, or a terminal green on more than one element; a light
  substrate and a dark substrate mixed within one interface. Consequence: a
  utilitarian palette stops meaning anything once a colour has no single job.
- Filed as taste, attribute off-direction-type: a serif set at reading length
  with no treatment. Consequence: this direction allows a serif only as a
  sparing, degraded disruption, and a plain one reads as a different
  publication.

Everything the other panels own, and every default tell not waived above, is
filed as usual.
