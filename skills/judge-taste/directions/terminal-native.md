A near-black working surface for people who read code. Monospace is a working
typeface here rather than an ornament, carrying labels, figures, eyebrows and
navigation; type is set tight; separation is a hairline at low contrast against
the ground rather than a box; and colour is one saturated accent, reserved for
the action and for state. The screen should read as the tool it is, not as a
page about the tool.

### Chosen on purpose

These are this direction's own language. Never file them as tells.

- A near-black ground is the direction, never a contrast tell in itself. Judge
  contrast on the text drawn against it, not on the choice of a dark surface.
- Monospace on labels, figures, navigation and eyebrows is the register, never
  a type tell, and neither is tight letter-spacing on display type.
- A command line, a code block or a configuration file as the main content of
  the first screen is this direction's hero, never the stock-hero tell.
- Hairline borders that sit only just above the ground are the separation
  method, never an unfinished or invisible edge.
- Terse, lowercase, technical labels are the voice, never a copy tell.

### What this direction adds

Filed under taste, with the attribute named, where a still shows it.

- Filed as taste, attribute off-direction-shape: generous corner rounding on a
  working surface, a primary action drawn as a capsule, or a card with a large
  radius wrapped around a code sample. Consequence: the shape reads as a
  consumer app dropped onto a developer surface, and the content it frames
  looks quoted rather than live.
- Filed as taste, attribute off-direction-colour: a multi-hue gradient wash, a
  glow behind a panel, or a second saturated accent beside the one the page
  already uses. Consequence: the accent stops meaning "this is the action" and
  becomes decoration, so nothing on the screen marks the next step.
- Filed as taste, attribute off-direction-ornament: an illustration, a mascot,
  or a rendered three-dimensional object on a working screen. Consequence: the
  one thing on the page that is not information takes the eye first.
- Filed as taste, attribute off-direction-type: a serif display face, or body
  text set with wide letter-spacing. Consequence: the register breaks, and a
  tool reads as a brochure about itself.
- Filed as taste, attribute off-direction-voice: superlatives and marketing
  claims where the screen is doing work. Consequence: the reader came to run
  something and is being sold it instead.

Everything the other panels own, and every default tell not waived above, is
filed as usual.
