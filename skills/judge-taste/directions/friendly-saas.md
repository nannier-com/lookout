Approachable software on a light ground. One bright accent used generously
rather than sparingly, corners rounded well past the point of comfort,
illustration doing real explanatory work, soft wide shadow as the only depth,
pastel fills behind icons and tags, and copy that speaks to the reader in the
second person. The screen should feel like it expects a person who has not read
the manual.

### Chosen on purpose

These are this direction's own language. Never file them as tells.

- Generous corner rounding, including a primary action drawn as a capsule, is
  this direction's shape, never a shape tell.
- An illustration, a character or a friendly spot drawing in the first screen
  is this direction's imagery, never an ornament tell. It carries meaning here
  rather than filling space.
- A soft, wide, low-opacity shadow under a card is the depth, never a shadow
  tell.
- A pastel fill behind an icon, a tag or a step number is the direction's
  colour, never an idle-badge tell where it labels something real.
- Warm second-person copy, contractions and a light joke in an empty state are
  the register, never a copy-voice tell.

### What this direction adds

Filed under taste, with the attribute named, where a still shows it.

- Filed as taste, attribute off-direction-colour: a near-black or fully
  desaturated surface used as the page ground, or the bright accent applied to
  so many elements at once that nothing is picked out. Consequence: the ground
  contradicts the welcome the direction is built on, or the accent stops
  pointing anywhere.
- Filed as taste, attribute off-direction-shape: zero-radius, hard-edged boxes
  and rules on a rounded surface. Consequence: two shape languages on one
  screen, and the harder one reads as a component from somewhere else.
- Filed as taste, attribute off-direction-type: a condensed or all-caps
  industrial face, or all-caps running text. Consequence: the type shouts on a
  screen whose whole method is not shouting.
- Filed as taste, attribute off-direction-voice: a terse technical register
  with the subject dropped, or an unexplained error code shown to the reader.
  Consequence: the screen stops speaking to the person it was drawn for, at the
  moment they most need it to.
- Filed as taste, attribute off-direction-icon: a dense row of small
  monochrome glyphs used as the main navigation, unlabelled. Consequence: the
  reader has to already know the product to use it.

Everything the other panels own, and every default tell not waived above, is
filed as usual.
