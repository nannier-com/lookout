Three more design directions ship: `terminal-native`, `cinematic-product` and
`friendly-saas`.

A project declares a direction so the taste panel judges against the look it chose instead
of against defaults, and so what it chose on purpose stops being filed as a tell. The four
directions that shipped until now left common looks uncovered, and a project whose look had
no preset had to write its own file or be judged against generic defaults.

`terminal-native` is the near-black working surface where monospace is a working typeface
and code is the content. `cinematic-product` is the near-black screen carrying one
full-bleed image, monumental display type and a single action. `friendly-saas` is the light
ground with one bright accent, generous rounding, illustration doing real work and a
second-person voice.

Each says what it settles, so those are never filed, and what it adds, in the attribute
vocabulary the taste panel already files under. Written as judging criteria in lookout's
own words, the way the taste tells were.

The preset list in a generated config now reads from the registry rather than repeating it,
so the two cannot drift apart again.
